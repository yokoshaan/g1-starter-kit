# テレオペ（Quest で腕を動かす）

Quest のコントローラの動きを、G1 の腕に追従させます。**腕だけ**を動かし、脚・腰は固定されたままです（歩行は付属リモコンで別途操作してください）。

---

## ⚠️ 実行前の確認

- 腕の可動範囲に**人・物が無い**
- ロボットが**安定して固定**されている（座位または吊り下げ）
- **電源をすぐ切れる位置**に人がいる
- 初回は必ず 2 人以上で

**起動直後、両腕が自動でゼロ姿勢へ動きます。** 安全パッチ（`setup/apply_patches.py`）が当たっていれば数秒かけてゆっくり動きます。当たっていないと高速で振られます。確認方法:

```bash
python3 setup/apply_patches.py --dry-run
```

`safe-startup` が「既に適用済み」と出ていれば大丈夫です。

---

## 起動

```bash
./scripts/teleop.sh              # 操作のみ
./scripts/teleop.sh --record     # 動きを記録しながら操作
```

起動時に表示されるもの:

```
==============================================
 XR テレオペ
  機体            : G1_29
  インターフェース: enp0s31f6
  記録            : あり → ~/xr_teleoperate/teleop/utils/data/demo/
----------------------------------------------
 ⚠️ 起動直後に両腕がゼロ姿勢へ動きます。周囲をクリアに。
 ...
  Quest のブラウザで開く URL:
    https://192.168.1.50:8012/?ws=wss://192.168.1.50:8012
==============================================
```

**29DoF 機の初回起動は 1 分ほど無反応になります。** 逆運動学のモデルを作り直しているだけなので、待ってください（2 回目以降はキャッシュが効いて速くなります）。

---

## Quest 側の手順

1. **Meta Quest ブラウザ**を開く
2. 起動時に表示された URL にアクセスする
3. 証明書の警告 → **「詳細設定 / Advanced」→「アクセスする / Proceed」**
   （自己署名証明書です。自分の PC が発行したものなので問題ありません）
4. **G1 の方を向いた状態で**、Meta ボタン長押し →「ビューをリセット」
5. ページの **「Virtual Reality」ボタン**を押す → 権限はすべて許可
6. パススルー（現実が見える状態）の没入ビューに入る

> **ページが開けているだけでは足りません。** 「Virtual Reality」ボタンを押して没入セッションに入らないと、頭やコントローラの姿勢が送られません。

## 操作

キーは**テレオペを起動したターミナル**で押します（Quest ではありません）。

| キー | 動作 |
|---|---|
| **`r`** | 追従開始 |
| **`s`** | 記録の開始 → もう一度押すと保存（`--record` 時のみ・`r` の後） |
| **`q`** | 終了。両腕が約 5 秒で初期姿勢へ戻ってから停止 |

**`Ctrl+C` は使わないでください。** 腕が戻らないまま制御が切れます。

### 追従を始めるコツ

`r` を押す前に、**コントローラをロボットの腕の今の位置・向きに合わせて**ください。ズレた状態で押すと、その差を埋めるために腕が急に動きます。

### 操作中の注意

- コントローラは**顔の前〜やや横**に留めてください。ヘッドセットのカメラ視界から外れる（特に真横や背後）と追従が止まります
- 基準の向きは「リセット / VR 突入したときの向き」で決まります。`head-reference` パッチが当たっていれば、**操作中にどこを向いても左右はズレません**

## 記録する

`--record` を付けて起動し、`r` で追従を始めたあとに `s` を押すと記録が始まります。もう一度 `s` で保存されます。

```bash
./scripts/teleop.sh --record
./scripts/teleop.sh --record --task pickup    # 保存先の名前を変える
```

保存先: `~/xr_teleoperate/teleop/utils/data/<名前>/episode_XXXX/`

```bash
./scripts/replay.sh --list      # 記録の一覧とフレーム数を見る
```

- **記録は `s` を押すまで始まりません。** 起動から Quest 接続、姿勢合わせまでの過程は入りません
- `s` は `r` の後でないと効きません
- 頭部カメラが無い環境では `Head image is None!` という警告が出続けますが、**正常です**（関節角の記録は続いています）

記録の中身と再生は [04-record-replay.md](04-record-replay.md) を参照してください。

---

## 終了

ターミナルで **`q`**。両腕が約 5 秒で初期姿勢へ戻ってから制御が終わります。

## この構成について

`scripts/teleop.sh` は `xr_teleoperate` を次の設定で起動しています。

| 引数 | 意味 |
|---|---|
| `--input-mode=controller` | コントローラ入力（手追従ではなく） |
| `--arm=G1_23` / `G1_29` | 機体の DoF。`config/g1.env` が `auto` なら自動判定 |
| `--display-mode=pass-through` | Quest のパススルーで現実を見ながら操作 |
| `--network-interface=<iface>` | ロボットと繋がっている有線インターフェース |
| （`--motion` を付けない） | デバッグモード。腕のみ制御し、他の関節はロック |

手追従（ハンドトラッキング）にしたい場合は `--input-mode=hand` を渡せますが、コントローラの方が安定して掴みやすいので既定にしています。

```bash
./scripts/teleop.sh --input-mode=hand    # 追加の引数はそのまま渡される
```
